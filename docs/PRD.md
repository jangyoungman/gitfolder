# 단위환산기 PRD (Product Requirements Document)

## 개요

다양한 단위를 간편하게 변환할 수 있는 웹 기반 단위환산기. 순수 HTML/CSS/JavaScript로 구현하며 별도 빌드 도구 없이 브라우저에서 바로 실행 가능하다.

## 기술 스택

- HTML5 / CSS3 / Vanilla JavaScript
- 단일 `index.html` 파일 (CSS, JS 인라인 포함)
- 외부 라이브러리 없음

## UI 구조

단일 페이지, 중앙 정렬 카드 레이아웃.

### 흐름

1. **카테고리 드롭다운** — 길이 / 무게 / 온도 / 부피 중 선택
2. 카테고리 선택 시 **변환 전 단위**와 **변환 후 단위** 드롭다운이 해당 카테고리 단위로 갱신
3. **값 입력 필드** — 숫자 입력
4. **변환 버튼** — 클릭 시 결과 표시
5. **스왑 버튼 (↔)** — 변환 전/후 단위를 교환하고, 입력값이 있으면 자동 재변환
6. **결과 표시 영역** — 변환 결과를 텍스트로 표시 (최대 6자리 유효숫자, 후행 0 제거)

## 지원 단위

| 카테고리 | 단위 | 기준 단위 |
|---------|------|----------|
| 길이 | km, m, cm, mm, inch, feet, yard, mile | m |
| 무게 | kg, g, mg, lb, oz, ton | kg |
| 온도 | °C, °F, K | °C |
| 부피 | L, mL, gallon, quart, pint, cup | L |

## 변환 로직

### 비율 기반 변환 (길이, 무게, 부피)

각 단위는 기준 단위와의 변환 비율(ratio)을 가진다.

```
결과 = 입력값 × (변환 전 단위의 ratio) / (변환 후 단위의 ratio)
```

#### 길이 (기준: m)

| 단위 | 비율 |
|------|------|
| km   | 1000 |
| m    | 1 |
| cm   | 0.01 |
| mm   | 0.001 |
| inch | 0.0254 |
| feet | 0.3048 |
| yard | 0.9144 |
| mile | 1609.344 |

#### 무게 (기준: kg)

| 단위 | 비율 |
|------|------|
| kg   | 1 |
| g    | 0.001 |
| mg   | 0.000001 |
| lb   | 0.453592 |
| oz   | 0.0283495 |
| ton  | 1000 |

> ton은 메트릭 톤(metric ton, 1000 kg) 기준이다.

#### 부피 (기준: L)

| 단위    | 비율 |
|---------|------|
| L       | 1 |
| mL      | 0.001 |
| gallon  | 3.78541 |
| quart   | 0.946353 |
| pint    | 0.473176 |
| cup     | 0.236588 |

> gallon은 US gallon 기준이다.

### 공식 기반 변환 (온도)

온도는 비율로 변환할 수 없으므로 별도 공식을 사용한다.

- °C → °F: `F = C × 9/5 + 32`
- °F → °C: `C = (F - 32) × 5/9`
- °C → K: `K = C + 273.15`
- K → °C: `C = K - 273.15`
- °F → K: `°F → °C → K`
- K → °F: `K → °C → °F`
